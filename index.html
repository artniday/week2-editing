Checking
  1. Paste the video ID or the full link. Both work, the ID is pulled out of a link automatically.
  2. Press Apply on this computer, go back to the activity, and play question 1.
  3. Watch the timecode readout. The first cut of the film must land at 01:18.9. If the copy runs early or late, put the difference in the offset box and apply again. Every question and every ribbon mark shifts together.
  4. When it lines up, paste the lines below into the CONFIG block at the top of the script in index.html and push to GitHub, or your students will still be watching whatever the file says.
FILM_SOURCE: "youtube",
FILM_YOUTUBE_ID: "",
FILM_OFFSET: 0

Streaming keeps the repository small and needs an open connection. The bundled file works on a locked down lab network and steps exactly one frame at a time, which matters for the cut on action questions. If you settle on streaming you can delete assets/videos/night-shift.mp4 and save 37 MB.

Class database connection
Checking
  1. Open the Firebase console and create a project. Analytics can be skipped.
  2. Go to Build, Realtime Database, Create Database. Pick the region closest to you.
  3. Copy the URL shown at the top of the database, then paste it in the box above and press Test connection.
  4. Open the Rules tab, replace what is there with the block below, and press Publish. Do not leave it in test mode, those rules stop working after thirty days and every save will silently fall back to the device.
  5. Once the test passes, paste the line below into index.html so every student writes to the same place, then push to GitHub.
{
  "rules": {
    "attempts": {
      ".read": true,
      ".write": true
    }
  }
}
FIREBASE_DB_URL: ""

These rules let anyone who knows the URL read, write and delete the attempts node. That is the trade for having no student sign in. This app stores only names, HCT IDs, answers and scores, so keep it to that, and empty the node at the end of each semester. Nothing else in the database is exposed, because the rules cover the attempts node alone.
